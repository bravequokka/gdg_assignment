----------------------------------
##오늘의 키워드 : component, post, props, array + map
---------------------------------
###component : 화면의 일부를 하나의 단위로 화면에서 찾은 구조를 코드에서도 표현하는 단위
- 대문자로 시작해야함
- jsx안에서 태그처럼 사용 가능
- 코드의 구조만 달라짐
- component로 나눠도 사용자가 보는 화면은 똑같음
- 같은 UI를 다시 사용하기 쉬워짐
-----------------------------------
###props : component에 값을 전달하는 방법
- 보내기 -> 받기 -> 보여주기
- 구조는 component로, 달라지는 값은 props로
